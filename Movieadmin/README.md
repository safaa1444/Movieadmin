# MoviesAdmin

## Project Description

MoviesAdmin is a movie administration website that allows users to manage a collection of movies.

Users can:

* Add new movies
* View movie details
* Edit existing movies
* Delete movies
* View movies sorted by release date

This project is part of a larger movie review website.

## Technologies Used

* ASP.NET Core MVC
* C#
* Entity Framework Core
* SQL Server
* Bootstrap

## Movie Information

Each movie includes:

* Title
* Synopsis
* Genre
* Rating
* Runtime (hours and minutes)
* Release Date
